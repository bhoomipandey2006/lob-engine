# Data source

`NIFTY50_15sec_20260917.csv` is real NSE Nifty 50 15-second OHLC price data
for 17 September 2026, sourced from the public, MIT-licensed repository:

https://github.com/technovusin/nifty50-historical-data

This is genuine, timestamped exchange price data. It is NOT full L2
order-book depth data (which requires a paid vendor feed or exchange
membership) — see the "Phase 2" section of the top-level README for exactly
what this data is used for and the honest limits of that use.
